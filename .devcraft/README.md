# DevCraft

## Overview

DevCraft is intended to become a full SpecKit replacement: a documentation-first workflow system for shaping software projects, tracking project context, controlling feature state, and guiding AI-assisted implementation through explicit approval gates.

The project starts from the DevCraft guidance currently maintained in `/Users/john/codex-setup` and will evolve into its own repository.

## Goals

- Make DevCraft a standalone reusable workflow system.
- Preserve strict documentation-first implementation gates.
- Provide console tooling for creating, managing, validating, and running DevCraft workflows.
- Improve the ergonomics of project setup, feature discovery, planning, analysis, and implementation tracking.

## Key Features

- DevCraft project control files under `.devcraft/`
- Feature lifecycle artifacts for specs, research, tasks, analysis, issues, and results
- Operator-controlled state transitions
- Console applications for workflow management
- Polished terminal UI using Spectre.Console
- ASCII-art support for console identity and banners

## Applications or Deliverables

- DevCraft repository structure
- DevCraft shared rules and templates
- .NET console tooling
- Documentation and workflow validation assets

## Notes

This repository is being built using DevCraft itself. Console applications are planned but not implemented until a DevCraft feature reaches `Implementation`.
